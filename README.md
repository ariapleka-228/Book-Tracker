## Описание программы

Book Tracker — это простое настольное приложение на Python с графическим интерфейсом, которое позволяет:

- Добавлять книги с названием, автором, жанром и количеством страниц.
- Просматривать список всех книг в виде таблицы.
- Фильтровать книги по жанру (частичное совпадение) и по количеству страниц — например, **больше 200**.
- Удалять выбранные книги.
- Сохранять данные в JSON-файл и автоматически загружать их при запуске.

---

## Инструкция по запуску

### 1. Убедитесь, что установлен Python 3.6+

Проверьте:
python --version

### 2. Скачайте или склонируйте данный репозиторий

### 3. Запустите приложение
bash
python book_tracker.py

## Примеры использования

### Добавление книги

text
Название: 1984
Автор: Джордж Оруэлл
Жанр: Антиутопия
Страницы: 328
→ Нажать "Добавить книгу"

### Фильтрация

В поле "Жанр" введите антиутопия → покажутся все антиутопии.

В поле "Страниц >" введите 300 → останутся только книги с числом страниц больше 300.

### Удаление
Кликните на книгу в таблице.

Нажмите 🗑 Удалить выбранную.

### Сохранение
Данные автоматически сохраняются в books.json. Также можно нажать 💾 Сохранить в JSON вручную.

## Тесты

### Действие и результат

Пустое поле при добавлении	❌ Ошибка "Все поля должны быть заполнены!"
В поле "Страницы" буквы	❌ Ошибка "Количество страниц должно быть целым числом!"
Фильтр "Страниц > abc"	❌ Ошибка "Значение страниц должно быть числом!"
Фильтр "Жанр: роман"	✅ Показываются только романы
Удаление без выбора	⚠️ Внимание "Выберите книгу для удаления!"
